## Project Overview

  

Menu Manager Appliaction is an app aimed to support chefs during their busy schedules. This app will allow the chefs to edit, deley, add and view their menu items.

The main goal for this application is to allow the chefs and support crew to know what the menu looks like without the use of papers that can fly away or get misplaced or lost during the diner, lunch or breakfast rush. 

It give the chef information in an instant while negating the overuse of paper.


  

## Website Goals and Objectives

  

The main goals of the website are:

- Provide chefs with information about the scheduled menu.

- Add menu items.

- Remove menu items.

- Filter the menu items.

- Search the menu items.

- Edit the menu items
